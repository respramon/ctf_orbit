# Wordlist bawaan

`web-small.txt` berisi 20 path umum untuk lab CTF. Komentar (`#`) dan baris
kosong diabaikan. Modul `web paths` memakai maksimal 20 permintaan secara
default, dengan jeda 0,2 detik dan tanpa mengikuti redirect.

Tambahkan path dari deskripsi challenge atau hasil triase. Semua path harus
berada pada origin URL yang dipilih. URL penuh, `//host`, backslash, dan
karakter `:` ditolak. Semua daftar di folder ini dibuat untuk proyek ini;
tidak menyertakan dump credential atau wordlist pihak ketiga.
